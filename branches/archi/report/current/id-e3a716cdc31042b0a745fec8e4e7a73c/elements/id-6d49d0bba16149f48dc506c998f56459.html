Security Monitoring/Audit Service ()
This service continuously monitors system logs and network traffic for suspicious activity and policy violations. It provides real-time alerts and detailed audit logs for forensic analysis. The purpose is to detect security incidents as they happen and provide the data needed for a rapid response. It ensures that any attempt to breach patient privacy is captured and reported. Example: An automated alert triggered when a user tries to access 1,000 patient records in a single minute.
