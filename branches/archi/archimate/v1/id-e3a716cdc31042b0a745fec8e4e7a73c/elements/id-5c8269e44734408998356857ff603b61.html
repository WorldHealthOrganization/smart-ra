Data Governance ()
This capability establishes the policies, standards, and rules for the quality, security, and ethical use of health data. It involves the management of metadata, data provenance, and stewardship responsibilities. The purpose is to ensure that data within the ecosystem is reliable, standardized, and used appropriately. It provides the framework for accountability and trust across all participating stakeholders. Example: A national data council defining the mandatory data quality standards for all PHR-contributing facilities.
