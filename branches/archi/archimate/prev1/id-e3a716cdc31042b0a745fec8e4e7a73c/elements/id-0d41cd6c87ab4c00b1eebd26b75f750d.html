Terminology Service (SNOMED, ICD, LOINC) ()
This service provides a centralized source for standardized clinical codes and vocabularies. It supports the translation and mapping between different medical coding systems. The purpose is to ensure that clinical data retains its meaning as it moves between different healthcare systems. This is the technical enabler for semantic interoperability and meaningful analytics. Example: A service that tells a reporting system that the local code "C-19" should be mapped to the ICD-10 code "U07.1".
