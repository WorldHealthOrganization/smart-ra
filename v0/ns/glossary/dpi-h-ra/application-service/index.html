Definition
  • An explicitly defined unit of application behaviour. Anch application service exposes the functionality of an application component to its environment. (en)
  • وحدة محددة صراحةً من سلوك التطبيق. وتتيح كل خدمة تطبيقية وظائف المكوّن التطبيقي لبيئته. (ar)
  • Unidad de comportamiento de la aplicación definida de forma explícita. Anch servicio de aplicación expone la funcionalidad de un componente de aplicación a su entorno. (es)
  • Unité explicitement définie de comportement applicatif. Anch service applicatif expose les fonctionnalités d'un composant applicatif à son environnement. (fr)
  • Явно определенная единица поведения приложения. Каждый сервис приложения предоставляет функциональные возможности компонента приложения его окружению. (ru)
  • 明确定义的应用行为单元。每个应用服务将应用组件的功能向其环境公开。 (zh)
