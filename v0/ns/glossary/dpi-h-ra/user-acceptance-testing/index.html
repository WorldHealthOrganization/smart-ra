Definition
  • User acceptance testing (UAT) is conducted to see whether the end-users are satisfied with the end product (24). (en)
  • يُجرى اختبار قبول المستخدم (UAT) لمعرفة ما إذا كان المستخدمون النهائيون راضين عن المنتج النهائي (24). (ar)
  • Las pruebas de aceptación del usuario (UAT) se realizan para comprobar si los usuarios finales están satisfechos con el producto final (24). (es)
  • Les tests d'acceptation par les utilisateurs (UAT) sont réalisés pour déterminer si les utilisateurs finaux sont satisfaits du produit final (24). (fr)
  • Приемочное тестирование пользователями (UAT) проводится для того, чтобы определить, удовлетворены ли конечные пользователи конечным продуктом (24). (ru)
  • 开展用户验收测试（UAT）是为了了解最终用户是否对最终产品感到满意 (24)。 (zh)
