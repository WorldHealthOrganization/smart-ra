Definition
  • A defined unit of structured data used or produced by an application component. (en)
  • وحدة محددة من البيانات المهيكلة يستخدمها مكوّن تطبيقي أو ينتجها. (ar)
  • Unidad definida de datos estructurados utilizada o producida por un componente de aplicación. (es)
  • Unité définie de données structurées utilisée ou produite par un composant applicatif. (fr)
  • Определенная единица структурированных данных, используемая или создаваемая компонентом приложения. (ru)
  • 应用组件所使用或产生的已定义的结构化数据单元。 (zh)
