Definition
  • Open-source software is software with source code that is published and made freely available to the public, enabling anyone to inspect, modify and enhance the code (18). While the source code is open to everyone, this does not mean that implementation of software is necessarily without costs. An open-source software must have a license approved by the Open Source Initiative (19). (en)
  • البرمجيات مفتوحة المصدر هي برمجيات تُنشر شفرتها المصدرية وتُتاح مجانًا للجمهور، بما يمكّن أي شخص من فحص الشفرة وتعديلها وتحسينها (18). ومع أن الشفرة المصدرية متاحة للجميع، فإن هذا لا يعني أن تنفيذ البرمجيات يكون بالضرورة دون تكاليف. ويجب أن تكون للبرمجيات مفتوحة المصدر رخصة معتمدة من Open Source Initiative (19). (ar)
  • El software de código abierto es software cuyo código fuente se publica y se pone a libre disposición del público, lo que permite a cualquier persona inspeccionar, modificar y mejorar el código (18). Aunque el código fuente está abierto a todos, esto no significa que la implementación del software esté necesariamente exenta de costos. Un software de código abierto debe tener una licencia aprobada por la Open Source Initiative (19). (es)
  • Un logiciel à code source ouvert est un logiciel dont le code source est publié et mis gratuitement à la disposition du public, ce qui permet à quiconque d'inspecter, de modifier et d'améliorer le code (18). Si le code source est ouvert à tous, cela ne signifie pas que la mise en œuvre du logiciel soit nécessairement sans coût. Un logiciel à code source ouvert doit disposer d'une licence approuvée par l'Open Source Initiative (19). (fr)
  • Программное обеспечение с открытым исходным кодом — это программное обеспечение, исходный код которого опубликован и находится в свободном доступе для общественности, что позволяет любому изучать, изменять и улучшать этот код (18). Хотя исходный код открыт для всех, это не означает, что внедрение программного обеспечения обязательно не сопряжено с затратами. Программное обеспечение с открытым исходным кодом должно иметь лицензию, одобренную Open Source Initiative (19). (ru)
  • 开源软件是指源代码公开发布并向公众免费提供的软件，使任何人都能检查、修改和改进代码 (18)。虽然源代码向所有人开放，但这并不意味着软件的实施必然没有成本。开源软件必须具有经开放源代码促进会（Open Source Initiative）批准的许可证 (19)。 (zh)
