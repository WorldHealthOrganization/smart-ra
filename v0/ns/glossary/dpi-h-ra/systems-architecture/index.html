Definition
  • The technical framework of the system depicted in a conceptual model that defines how the system is structured and how its elements are connected. (en)
  • الإطار التقني للنظام مصوَّرًا في نموذج مفاهيمي يحدد كيفية هيكلة النظام وكيفية الربط بين عناصره. (ar)
  • Marco técnico del sistema, representado en un modelo conceptual, que define cómo está estructurado el sistema y cómo se conectan sus elementos. (es)
  • Cadre technique du système, représenté dans un modèle conceptuel, qui définit la manière dont le système est structuré et dont ses éléments sont connectés. (fr)
  • Техническая основа системы, отображенная в концептуальной модели, которая определяет, как структурирована система и как связаны ее элементы. (ru)
  • 以概念模型描述的系统技术框架，界定系统的结构方式及其各要素的连接方式。 (zh)

Scope note
PHC handbook glossary wording, verbatim (who-iris/library/9789240093362-eng/sections/sec-002-glossary.md, p. 11). Wording alternative in SC handbook glossary (who-iris/library/9789240101197-eng/sections/page-009.md, p. 9): "A technical framework based on a conceptual model that defines how the system should be structured and how its elements should be connected." Internal alternative in PHC handbook §4.4 body under 'system architecture' (who-iris/library/9789240093362-eng/sections/sec-023-44-design-system-architecture.md, pp. 56-60): "A system architecture is a conceptual model that depicts how the PCPOSS will be structured and how it functions and includes all the software and hardware components that comprise the system." All are recorded as candidates; none is chosen (smart-ra#133 S1, smart-ra#200).
