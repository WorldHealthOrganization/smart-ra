Functional application (en)
Definition
  • Functional applications are application components that deliver a specific operational function within a defined domain. They are context-specific, reflecting the operational requirements of a programme, scheme, or institution that procures them. (en)
  • التطبيقات الوظيفية هي مكونات تطبيقية تؤدي وظيفة تشغيلية محددة ضمن مجال محدد. وهي خاصة بالسياق، وتعكس المتطلبات التشغيلية للبرنامج أو المخطط أو المؤسسة التي تشتريها. (ar)
  • Las aplicaciones funcionales son componentes de aplicación que cumplen una función operativa específica dentro de un dominio definido. Son específicas del contexto y reflejan los requisitos operativos del programa, régimen o institución que las adquiere. (es)
  • Les applications fonctionnelles sont des composants applicatifs qui assurent une fonction opérationnelle spécifique dans un domaine défini. Elles sont propres à un contexte et reflètent les exigences opérationnelles d'un programme, d'un régime ou d'une institution qui en fait l'acquisition. (fr)
  • Функциональные приложения — это компоненты приложений, которые выполняют конкретную операционную функцию в пределах определенной области. Они зависят от контекста и отражают операционные требования программы, схемы или учреждения, которые их закупают. (ru)
  • 功能性应用是在特定领域内提供特定业务职能的应用组件。它们因情境而异，反映采购它们的规划、计划或机构的业务需求。 (zh)
