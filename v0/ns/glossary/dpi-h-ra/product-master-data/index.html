Definition
  • Product master data consists of standardized information that accurately describes a health product’s characteristics. This data remains consistent across all instances of a product. (en)
  • تتألف البيانات الرئيسية للمنتج من معلومات موحدة تصف خصائص المنتج الصحي بدقة. وتظل هذه البيانات متسقة في جميع حالات المنتج. (ar)
  • Los datos maestros de productos consisten en información normalizada que describe con exactitud las características de un producto de salud. Estos datos se mantienen uniformes en todas las instancias de un producto. (es)
  • Les données de référence des produits consistent en des informations normalisées qui décrivent avec exactitude les caractéristiques d'un produit de santé. Ces données restent identiques pour toutes les occurrences d'un produit. (fr)
  • Мастер-данные продукции состоят из стандартизированной информации, точно описывающей характеристики продукции медицинского назначения. Эти данные остаются неизменными во всех экземплярах продукта. (ru)
  • 产品主数据由准确描述卫生产品特征的标准化信息组成。这些数据在产品的所有实例中保持一致。 (zh)
