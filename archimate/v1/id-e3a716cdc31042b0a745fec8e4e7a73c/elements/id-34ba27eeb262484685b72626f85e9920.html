Facility Registry ()
A facility registry maintains standardized information about healthcare facilities, service locations, and operational characteristics. It supports accurate identification and classification of healthcare institutions. The purpose of this data object is to improve coordination, referrals, and reporting across the healthcare system. It also supports interoperability and healthcare network management. Example: A referral platform identifies the nearest accredited dialysis center using facility registry information.
