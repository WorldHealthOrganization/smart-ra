Application Component ()
The deployed IT system that provides the functionality. Components encapsulate logic and data, and expose their behavior through services. They are modular, replaceable, and reusable. For example, the Client Registry, Interoperability Middleware, or Terminology Serviceer are application components within DPI-H.
