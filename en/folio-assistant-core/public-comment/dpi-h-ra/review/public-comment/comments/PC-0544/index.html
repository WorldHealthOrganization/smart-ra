comment
Section 3.2 states at lines 127–132 that "an element shown in a view represents a capability or a type of component and the role it plays, not an instruction to procure a particular system", and that the architecture "leaves the choice of implementation … to the country"; line 117 describes the model as offering "a common structure and vocabulary, not a prescription". In Figure 3.2, however, the Lifelong Health Record element in the Shared Data Layer is annotated "FHIR-based store". That is an implementation prescription for the persistence of the national clinical record, and it is the only element in the figure annotated with a storage technology. The identical annotation appears a second time in Figure 3.5 on page 66, which repeats the same Shared Data Layer, so the prescription is stated twice and both occurrences need the same correction. It also sits uneasily with Appendix C page 155 lines 15–25, which states that the LHR "is defined by its outcome, not by its implementation model"; with section 3.6.2 line 813, which scopes HL7 FHIR to "the exchange-oriented representation of health data"; and with section 4.3.3 lines 319–321. Figure 3.2 is the artefact most likely to be reproduced in national architecture documents, so an annotation of this kind propagates further than the surrounding text.
