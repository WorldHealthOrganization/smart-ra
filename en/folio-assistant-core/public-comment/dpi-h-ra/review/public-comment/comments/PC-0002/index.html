comment
The draft names this hazard itself: without semantic governance, "the same coded value is interpreted differently by different systems, or systems maintain inconsistent local copies of code systems, making aggregation and comparison unreliable" (p.69). The contract the requirements then write is asymmetric. Two components are Required to consume a capability the provider is only advised to offer. Public Health Surveillance Platform requirement 18 is Required: the platform "shall subscribe to update notifications from the Terminology Service to ensure surveillance case definitions and reporting forms remain aligned with current terminology versions as international standards evolve" (p.226). Logical Information Model Repository requirement 7 is Required on the same pattern (p.176). The corresponding provider capability, requirement 21, by which a consuming system learns that an artefact was "updated, deprecated, or retired", is Recommended (p.170). The nearest thing the draft does require is Public Health Surveillance Platform requirement 19 (p.226, Required), which monitors the "timeliness, completeness, and quality of surveillance data submissions" with alerts on threshold breach. That is a check on the volume, timeliness and quality of submissions. Its thresholds are set nationally, so whether the silent absence of one newly notifiable condition registers depends on how finely they are configured. Nothing in the requirement obliges that granularity, and nothing in it requires the platform to establish that a particular consumer has received a particular published change. A detection that depends on how an implementer happens to configure a threshold is not the same as a requirement that the state be demonstrable. Appendix F carries many of the enabling capabilities but is "illustrative reference material rather than a specification" (p.241). Gap detection, replay, resynchronisation, omission, cursor, sequence number, manifest and checksum return no occurrences anywhere in the draft. The reasoning, a worked case and the measurement proposal are set out in the companion paper attached to this submission.
