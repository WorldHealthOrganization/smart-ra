title
Restructure the Product Registry data model by product class
requirements
- Model units, strength, routes, storage conditions and classifications as structured, governed attributes - Distinguish clinical concept, regulated product, item, packaging level, batch and serial instance - Add applicability by product class and identification level to the data-element table - Define a governed clinical-product model and identifier scheme - Model repeatable packaging relationships down to the smallest base unit - Make GTIN, brand name, medicinal attributes, origin, shelf life, dimensions and generic mapping conditional where not universally applicable - Link manufacturers and related parties to authoritative organisation records - Govern units and conversions, referencing UCUM where applicable, with integrity checks
