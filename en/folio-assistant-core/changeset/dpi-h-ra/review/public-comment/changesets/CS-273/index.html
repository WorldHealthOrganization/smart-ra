title
Define a minimum SGI baseline and progressive maturity levels
requirements
- Identify the minimum SGI capabilities needed before a country publishes national terminology, models or IGs, and mark which belong to the REDDHI baseline - Define the minimum semantic-governance baseline (ownership, identifiers, versioning, approval, change control) needed before data structures go live - Explain how the terminology maturity model extends to other artefact types - Clarify that governed models exist from the outset but may be published through simpler means first - Describe progressive maturity stages and give short examples at each level - Place that baseline in Phases 1–2, reserving advanced SGI capabilities for Phase 3 - Describe the criteria distinguishing each maturity level so maturity is not read as technology sophistication - Describe a maturity path rather than mandatory runtime prerequisites
